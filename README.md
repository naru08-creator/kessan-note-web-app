# 決算ノート（Web公開版）

## データの保存について

- 入力したデータは、アクセスした人それぞれの**ブラウザのlocalStorage**に保存されます
- 保存先はブラウザごと・端末ごとに独立しています（あなたが他の人のデータを見ることはできませんし、他の人があなたのデータを見ることもできません）
- ブラウザのキャッシュ／サイトデータを削除すると消えます。同じ人でもスマホとPCなど別の端末からは別データになります（自動同期はされません）
- 画面上部の「📥 CSVでバックアップ」から、全データをzip（証券コード_年度.csv が1年度・1ファイル）としてダウンロードできます。「📤 CSVを読み込む」からそのzipや個別のCSVを読み込んで復元できます
- このCSV形式はElectron版のファイル形式と同じです。Web版でバックアップしたzipをElectron版の保存フォルダに展開すれば、そのまま読み込めます

## 今のフル機能

- 複数企業のノート管理（会社追加・年度追加）
- P/L・B/S・C/F・指標・メモの入力（自動計算項目あり、用語の「？」で説明表示）
- IFRS表記への切り替え
- グラフ表示ページ（P/L構成・B/S構成比較・CF滝グラフ・複数年推移）
- 会社比較ページ（2社×年度を選んで比較、構成比較／実額比較の切り替え）
- CSVバックアップ・読み込み
- 印刷／PDF保存
