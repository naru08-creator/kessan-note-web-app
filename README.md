# 決算ノート（Web公開版）

GitHub Pagesなどにそのまま置けば、誰でもアクセスできる公開ツールになります。
ビルド不要（Vite/webpack不要）。React・Recharts・Babelは全てCDNから読み込みます。

## 公開手順（GitHub Pages）

1. このフォルダの中身（`index.html` と `core/` フォルダ）をリポジトリにコミットする
   ```
   your-repo/
   ├─ index.html
   └─ core/
      └─ kessan-core.js
   ```
2. GitHubリポジトリの Settings → Pages で、公開元のブランチ／フォルダを指定する
3. 発行されたURL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）にアクセスすれば使える

## データの保存について

- 入力したデータは、アクセスした人それぞれの**ブラウザのlocalStorage**に保存されます
- 保存先はブラウザごと・端末ごとに独立しています（あなたが他の人のデータを見ることはできませんし、他の人があなたのデータを見ることもできません）
- ブラウザのキャッシュ／サイトデータを削除すると消えます。同じ人でもスマホとPCなど別の端末からは別データになります（自動同期はされません）
- 画面上部の「📥 CSVでバックアップ」から、全データをzip（証券コード_年度.csv が1年度・1ファイル）としてダウンロードできます。「📤 CSVを読み込む」からそのzipや個別のCSVを読み込んで復元できます
- このCSV形式はElectron版のファイル形式と同じです。Web版でバックアップしたzipをElectron版の保存フォルダに展開すれば、そのまま読み込めます

## 広告枠・ブログへの導線について

`index.html`に、Admaxなどの広告コードをそのまま貼り付けられる空の枠を用意しています。

- `#ad-header` … ページ上部（ヘッダー枠）
- `#ad-footer` … ページ下部（フッター枠）
- `#ad-rail-left` / `#ad-rail-right` … 画面幅が広いPCでのみ表示されるサイドレール枠（幅1300px未満では自動的に非表示）

広告コードが発行されたら、該当する`<div id="...">`の中にそのままタグを貼り付ければ反映されます。空のままなら場所を取らないようになっています。

ページ上部には「← えるぴょんのゆる投資日記に戻る」というブログへの導線リンクも入れてあります。リンク先URL（`erupyon.hatenablog.com`）が変わった場合は、`index.html`内の該当箇所を書き換えてください。

## 今のフル機能

- 複数企業のノート管理（会社追加・年度追加）
- P/L・B/S・C/F・指標・メモの入力（自動計算項目あり、用語の「？」で説明表示）
- IFRS表記への切り替え
- グラフ表示ページ（P/L構成・B/S構成比較・CF滝グラフ・複数年推移）
- 会社比較ページ（2社×年度を選んで比較、構成比較／実額比較の切り替え）
- CSVバックアップ・読み込み
- 印刷／PDF保存

## 今後拡張したい場合

- `core/kessan-core.js` はElectron版と共通のファイルです。デザインや機能を変えたい場合はこのファイル1つを直せば両方に反映されます
- `index.html` 側（このファイル）を直すのは「保存方法」や「見た目の枠」だけにしておくと、今後もコードの使い回しがしやすくなります
