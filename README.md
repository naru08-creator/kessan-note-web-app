# 決算ノート（Web公開版）

GitHub Pagesなどにそのまま置けば、誰でもアクセスできる公開ツールになります。
ビルド不要（Vite/webpack不要）。React・Recharts・Babelは全てCDNから読み込みます。

## 公開手順（GitHub Pages）

1. このフォルダの中身（`index.html` と `core/` フォルダ）をリポジトリにコミットする
   ```
   your-repo/
   ├─ index.html
   └─ core/
      └─ kessan-core.js
   ```
2. GitHubリポジトリの Settings → Pages で、公開元のブランチ／フォルダを指定する
3. 発行されたURL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）にアクセスすれば使える

## データの保存について

- 入力したデータは、アクセスした人それぞれの**ブラウザのlocalStorage**に保存されます
- 保存先はブラウザごと・端末ごとに独立しています（あなたが他の人のデータを見ることはできませんし、他の人があなたのデータを見ることもできません）
- ブラウザのキャッシュ／サイトデータを削除すると消えます。バックアップ機能はまだ付いていません
- 同じ人でもスマホとPCなど別の端末からは別データになります（同期はされません）

## 今のフル機能

- 複数企業のノート管理（会社追加・年度追加）
- P/L・B/S・C/F・指標・メモの入力（自動計算項目あり）
- IFRS表記への切り替え
- グラフ表示ページ（P/L構成・B/S構成比較・CF滝グラフ・複数年推移）
- 会社比較ページ（2社×年度を選んで比較）
- 印刷／PDF保存

## 今後拡張したい場合

- `core/kessan-core.js` はElectron版と共通のファイルです。デザインや機能を変えたい場合はこのファイル1つを直せば両方に反映されます
- `index.html` 側（このファイル）を直すのは「保存方法」や「見た目の枠」だけにしておくと、今後もコードの使い回しがしやすくなります
